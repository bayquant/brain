# Brain

A personal knowledge vault!

## Writing Guide

See `brain/CLAUDE.md` for guidelines on:
- File naming conventions (Title Case with spaces)
- Frontmatter and tag structure
- Heading hierarchy and formatting
- Code blocks, links, lists, and tables

## Quick Start

1. Open with Obsidian
2. Create new notes following the template in `CLAUDE.md`
3. Use `[[Note Title]]` to link between notes
4. Tag notes with kebab-case tags for organization
